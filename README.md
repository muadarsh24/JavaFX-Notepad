# JavaFX Notepad

A desktop text editor built using Java and JavaFX.

## About

This project is a Notepad-style text editor that allows users to create, open, edit, save, and print text documents through a graphical user interface.

## Features

### File Management
- Create new documents
- Open existing text files
- Save documents
- Save As functionality
- Exit application

### Text Editing
- Undo and redo
- Cut, copy, and paste
- Delete selected text
- Select all text

### Formatting
- Select from available font families
- Customize font size
- Bold and italic formatting
- Toggle word wrapping

### View
- Zoom in and zoom out while maintaining the current font style

### Page Setup and Printing
- Choose between Letter, Legal, and A4 paper sizes
- Select portrait or landscape orientation
- Print documents using JavaFX PrinterJob


## Technologies Used

- Java
- JavaFX
- Java NIO (File I/O)

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Allow IntelliJ to configure the project and download any required dependencies.
4. Locate `HelloApplication.java`.
5. Run the application.
